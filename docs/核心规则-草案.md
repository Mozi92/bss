> **文档状态**：草案（Draft）

> **编制人**：张牧之
> **编制日期**：2026年

## 1. 模式概述

33复制模式是一种基于用户推荐的推广激励机制，核心逻辑为：**每位推广者最多直接推荐3位新用户**，通过直推奖励（按订单金额比例）与间推奖励（按件数固定金额）双重激励，鼓励推广者积极分享产品并带动新用户参与。

**核心规则**：同一推广者在不同订单中，**可以分别获得直推奖励和间推奖励**，两者互不排斥、可叠加累计。同时，同一推广者在同一订单中不重复获得两种奖励，避免利益重叠。

该模式强调 **“分享推荐、自然裂变”**，充分利用运营方现有的人脉资源实现用户增长。


## 2. 核心概念定义

| 术语 | 定义 |
|------|------|
| **推广者** | 满足条件后获得推荐资格的注册用户，可推荐新用户并获得推广奖励积分 |
| **推荐用户** | 由某推广者直接推荐发展的新用户，每位推广者最多3位 |
| **推荐人** | 推荐并发展当前用户的推广者，即“谁推荐的谁” |
| **挂靠上级** | 当前用户在推广体系中的上一层级节点（可能非推荐人） |
| **直推奖励** | 推荐人从被推荐用户的订单中按比例获得奖励积分（按单计算） |
| **间推奖励** | 非推荐人的层级节点按固定金额获得奖励积分（按件计算） |
| **自动分配** | 当某推广者已推荐满3位用户后，后续用户由系统自动分配至下级名下 |
| **顶层节点** | 推广体系最顶端的账号，无上级节点，通常为平台合作方指定 |


## 3. 层级结构规则

### 3.1 基本结构

```
        顶层节点
        /   |   \
    第1位  第2位  第3位     ← 每位推广者最多推荐3位用户
     /|\    /|\    /|\
    ...    ...    ...       ← 下级同样各自推荐3位
```

### 3.2 推荐规则

| 规则项 | 说明 |
|--------|------|
| 推荐用户上限 | 每位推广者最多推荐 **3位** 新用户 |
| 第4位处理 | 由系统自动分配至已有下级名下（按系统规则） |
| 分配顺序 | 可按注册时间、活跃度或系统算法自动分配 |
| 层级深度 | 理论不限，实际受奖励分配层级限制 |
| 推荐关系 | 一旦建立，**不可自行变更** |
| 挂靠关系 | 可随系统分配规则动态调整 |


## 4. 推广奖励积分体系

### 4.1 积分基本规则

| 项目 | 说明 |
|------|------|
| 积分与人民币兑换 | 1积分 = 1元人民币 |
| 积分来源 | 仅通过推广奖励获得，不可充值购买 |
| 积分有效期 | 12个月（自获得之日起），过期自动清零 |
| 兑换方式 | 申请兑换，由运营方审核后线下转账 |
| 最低兑换额度 | 100积分 |
| 兑换频率 | 每月最多2次 |
| 积分状态 | 发放后进入冻结状态，退款保护期满后转为可结算 |


### 4.2 推广奖励类型

| 类型 | 计算方式 | 计算基础 | 奖励对象 |
|------|----------|----------|----------|
| **直推奖励** | 按订单金额比例 | **按订单（每单）** | 始终为推荐人 |
| **间推奖励** | 固定金额 | **按件数（每件）** | 非推荐人的层级节点 |


### 4.3 直推与间推叠加规则

| 规则项 | 说明 |
|--------|------|
| 叠加原则 | 同一推广者在 **不同订单** 中可分别获得直推奖励和间推奖励，两者互不排斥，可叠加累计 |
| 触发场景 | 推广者A推荐了B，B推荐了C。C下单时，B获得直推奖励；A作为B的推荐人，在间推分配中B所在层级被跳过，A获得间推奖励 |
| 同一订单规则 | 同一推广者在 **同一订单** 中不重复获得直推和间推奖励，间推分配时跳过该订单的推荐人 |
| 互斥关系 | 直推与间推在 **同一订单中互斥**（推荐人只获直推），在 **不同订单中可叠加** |


## 5. 直推奖励规则（按订单比例）

### 5.1 直推奖励比例分配

每位推广者名下的3位推荐用户，其对应的直推奖励比例 **可不同**，通过差异化比例激励推广者积极推荐。

| 推荐用户序号 | 直推奖励比例 | 说明 |
|-------------|-------------|------|
| 第1位推荐用户 | **20%** | 该用户每笔订单金额的20%作为推荐奖励 |
| 第2位推荐用户 | **20%** | 该用户每笔订单金额的20%作为推荐奖励 |
| 第3位推荐用户 | **60%** | 该用户每笔订单金额的60%作为推荐奖励 |

> **激励逻辑**：第3位推荐用户的直推奖励比例较高，旨在鼓励推广者积极完成3位推荐，形成完整的33复制结构。

### 5.2 直推奖励核心规则

| 规则项 | 说明 |
|--------|------|
| 计算基础 | **按订单（每单）** 计算，与订单内产品件数无关 |
| 奖励对象 | **始终为当前用户的推荐人** |
| 奖励比例 | 根据该用户在推荐人名下的序号确定（20%/20%/60%） |
| 是否受挂靠影响 | **否**，直推奖励不受挂靠层级影响，只看“谁推荐的” |
| 与间推关系 | 不同订单中可叠加获得 |

### 5.3 直推奖励计算示例

```
场景：
- 推广者A推荐了3位用户：B1（第1位）、B2（第2位）、B3（第3位）
- 产品单价：100元/件

示例1：B1下单购买1件（订单金额100元）
→ A获得直推奖励：100 × 20% = 20积分

示例2：B2下单购买5件（订单金额500元）
→ A获得直推奖励：500 × 20% = 100积分（直推按单计算，不看件数）

示例3：B3下单购买2件（订单金额200元）
→ A获得直推奖励：200 × 60% = 120积分（直推按单计算，不看件数）
```


## 6. 间推奖励规则（按件固定金额）

### 6.1 间推奖励标准

| 项目 | 标准值 | 说明 |
|------|--------|------|
| 间推固定金额 | **30积分/件** | 每件产品产生30积分间推奖励 |
| 间推计算基础 | 按件数计算 | 与产品单价无关 |
| 间推奖励对象 | 非推荐人的层级节点 | 推荐人已通过直推奖励获取收益，不参与本单间推分配 |

### 6.2 间推核心分配逻辑

**核心原则**：从当前用户往上逐层检查，每件产品产生一笔30积分的间推奖励，分配给 **最近的非推荐人层级节点**。如果某层级节点恰好是当前用户的推荐人，则 **跳过该层级**，间推奖励继续向上分配给更上一层的非推荐人节点。

**分配规则：**

1. 直推奖励始终分配给 **推荐人**
2. 间推奖励从当前用户往上逐层寻找 **非推荐人** 节点进行分配
3. 每件产品对应一层间推奖励，逐件向上分配
4. 遇到推荐人所在层级时，跳过该层级，间推继续向上
5. 到达顶层节点或件数用完时停止

### 6.3 间推分配逻辑流程

```
用户下单N件产品：

第1件 → 检查上一层：
  ├─ 上一层 = 推荐人？ → 跳过，间推给往上第2层（30积分）
  └─ 上一层 ≠ 推荐人？ → 间推给上一层（30积分）

第2件 → 从第1件分配到的层级继续往上：
  ├─ 该层 = 推荐人？ → 跳过，间推继续向上
  └─ 该层 ≠ 推荐人？ → 间推给该层（30积分）

第3件、第4件……以此类推，直到顶层或件数用完
```

### 6.4 间推完整计算示例

#### 示例1：上一层就是推荐人

```
场景：
- A推荐了B（B是A的第1位推荐用户，直推比例20%）
- B下单购买3件产品（每件100元，订单总金额300元）

奖励分配：
┌─────────┬──────────────────┬──────────────────────┬──────────┐
│ 产品件数 │ 奖励类型         │ 获得者               │ 奖励金额 │
├─────────┼──────────────────┼──────────────────────┼──────────┤
│ 整单     │ 直推（20%）      │ A（推荐人）          │ 60积分   │
│ 第1件    │ 间推（固定30）   │ A的上一层（跳过A）   │ 30积分   │
│ 第2件    │ 间推（固定30）   │ 再往上一层           │ 30积分   │
│ 第3件    │ 间推（固定30）   │ 再往上一层           │ 30积分   │
└─────────┴──────────────────┴──────────────────────┴──────────┘

说明：B的上一层就是A（推荐人），A已通过直推获得60积分，
      因此B这一单的间推跳过A，分配给A的上一层。
```

#### 示例2：上一层不是推荐人（挂靠关系）

```
场景：
- A推荐了B（B是A的第3位推荐用户，直推比例60%）
- B推荐了C，但C挂靠在D名下（D不是C的推荐人，B才是）
- 挂靠结构：D（上一层）→ C（当前用户）
- 推荐关系：B → C

层级结构（从C往上）：
  第3层：A
  第2层：B（C的推荐人）
  第1层：D（C的挂靠上级，非推荐人）
  第0层：C（下单用户）

C下单购买4件产品（每件100元，订单总金额400元）：

奖励分配：
┌─────────┬──────────────────┬──────────────────────┬──────────┐
│ 产品件数 │ 奖励类型         │ 获得者               │ 奖励金额 │
├─────────┼──────────────────┼──────────────────────┼──────────┤
│ 整单     │ 直推（60%）      │ B（推荐人）          │ 240积分  │
│ 第1件    │ 间推（固定30）   │ D（上一层，非推荐人）│ 30积分   │
│ 第2件    │ 间推（固定30）   │ 跳过B → 分配给A     │ 30积分   │
│ 第3件    │ 间推（固定30）   │ A的上一层            │ 30积分   │
│ 第4件    │ 间推（固定30）   │ 再往上一层           │ 30积分   │
└─────────┴──────────────────┴──────────────────────┴──────────┘

说明：
- B获得直推奖励240积分（C的订单整单金额 × 60%）
- B在C的这笔订单中不参与间推分配（间推跳过推荐人）
- D获得第1件间推奖励30积分
- A获得第2件间推奖励30积分（B被跳过，A作为B的上一层获得）
```

#### 示例3：同一推广者在不同订单中分别获得直推和间推

```
场景：
- A是推广者
- A推荐了B（B是A的第2位推荐用户，直推比例20%）
- B推荐了C（C是B的第1位推荐用户，直推比例20%）

层级结构（从C往上）：
  第2层：A（B的推荐人）
  第1层：B（C的推荐人）
  第0层：C（下单用户）

C下单购买3件产品：

C的订单奖励分配：
┌─────────┬──────────────────┬──────────────────────┬──────────┐
│ 产品件数 │ 奖励类型         │ 获得者               │ 奖励金额 │
├─────────┼──────────────────┼──────────────────────┼──────────┤
│ 整单     │ 直推（20%）      │ B（C的推荐人）       │ 60积分   │
│ 第1件    │ 间推（固定30）   │ 跳过B → 分配给A     │ 30积分   │
│ 第2件    │ 间推（固定30）   │ A的上一层            │ 30积分   │
│ 第3件    │ 间推（固定30）   │ 再往上一层           │ 30积分   │
└─────────┴──────────────────┴──────────────────────┴──────────┘

B的收益：
- C的订单：直推奖励60积分

A的收益：
- C的订单：间推奖励30积分（第1件间推跳过B后分配给A）
- 当B下单时：A还可获得直推奖励（B是A的第2位推荐用户，直推比例20%）

说明：A在不同订单中分别获得了间推奖励（来自C的订单）和直推奖励（来自B的订单），
      两者互不排斥，可叠加累计。
```


## 7. 特殊情况处理

| 场景 | 处理规则 |
|------|----------|
| 下单件数超过可分配层级数 | 超出部分不再分配，归入平台收益 |
| 到达顶层仍有多余件数 | 剩余件数对应的间推奖励归入平台收益 |
| 连续多层都是推荐人 | 跳过所有推荐人层级，继续向上分配给最近的非推荐人 |
| 退款/退货 | 对应订单的全部推广奖励收回（含直推和间推） |
| 部分退款 | 按退款比例收回对应推广奖励（含直推和间推） |
| 同一层级存在多个挂名用户 | 按系统挂靠顺序依次分配 |
| 产品单价变化 | 间推固定金额不受影响，始终按30积分/件计算 |
| 产品组合购买 | 按总件数计算，每件均触发一层间推分配 |
| 推荐用户注销/退出 | 其下级自动上移或由系统重新分配挂靠 |
| 奖励账户余额不足扣除 | 记录负余额，后续获得奖励时优先抵扣 |
| 同一推广者多角色 | 允许同一推广者在不同订单中分别获得直推和间推奖励，互不排斥 |

## 9. 直推与间推关系总结

| 对比项 | 直推奖励 | 间推奖励 |
|--------|----------|----------|
| 计算基础 | **按订单（每单）** | **按件数（每件）** |
| 计算方式 | 比例（20%/20%/60%） | 固定金额（30积分/件） |
| 奖励对象 | **始终为推荐人** | **非推荐人的层级节点** |
| 是否受挂靠影响 | **否**，只看推荐关系 | **是**，按挂靠层级逐层向上 |
| 遇到推荐人层级 | 直接分配给推荐人 | **跳过**，继续向上分配给非推荐人 |
| 一单多件时 | 只计算一次（按整单金额×比例） | 每件分别计算（每件对应一层） |
| 不同订单叠加 | ✅ 可叠加获得 | ✅ 可叠加获得 |
| 同一订单冲突 | 推荐人获得直推，不参与间推 | 间推跳过推荐人 |


## 10. 推广奖励计算完整示例

### 10.1 完整场景

```
推广体系结构：
  第3层：P（顶层节点）
  第2层：A（P的第1位推荐用户）
  第1层：B（A的第2位推荐用户）
  第0层：C（B的第1位推荐用户）

推荐关系：
  P → A（A是P的第1位推荐用户，直推比例20%）
  A → B（B是A的第2位推荐用户，直推比例20%）
  B → C（C是B的第1位推荐用户，直推比例20%）

挂靠关系：
  P → A → B → C（正常挂靠链）
```

### 10.2 C下单5件产品的推广奖励分配

C下单5件产品（每件100元，订单总金额500元）：

| 奖励类型 | 计算方式 | 获得者 | 金额 | 说明 |
|----------|----------|--------|------|------|
| 直推 | 500 × 20% | B | 100积分 | B是C的推荐人（C是B第1位推荐用户） |
| 间推-第1件 | 固定30 | A | 30积分 | C的上一层是B（推荐人）→跳过B→分配给A |
| 间推-第2件 | 固定30 | P | 30积分 | A的上一层是P（非推荐人）→分配给P |
| 间推-第3件起 | — | 无 | 0积分 | P是顶层节点，无更上层，停止分配 |

**汇总**：
- B获得：直推奖励100积分
- A获得：间推奖励30积分
- P获得：间推奖励30积分
- 平台留存：500 - 100 - 30 - 30 = 340元

### 10.3 B下单3件产品的推广奖励分配

B下单3件产品（每件100元，订单总金额300元）：

| 奖励类型 | 计算方式 | 获得者 | 金额 | 说明 |
|----------|----------|--------|------|------|
| 直推 | 300 × 20% | A | 60积分 | A是B的推荐人（B是A第2位推荐用户） |
| 间推-第1件 | 固定30 | P | 30积分 | B的上一层是A（推荐人）→跳过A→分配给P |
| 间推-第2件起 | — | 无 | 0积分 | P是顶层节点，停止分配 |

**汇总**：
- A获得：直推奖励60积分
- P获得：间推奖励30积分

### 10.4 A的累计收益展示

A在上述两笔订单中的总收益：

| 来源订单 | 奖励类型 | 金额 |
|----------|----------|------|
| C的订单 | 间推奖励（第1件） | 30积分 |
| B的订单 | 直推奖励 | 60积分 |
| **合计** | | **90积分** |

> **说明**：A同时获得了直推奖励（来自B的订单）和间推奖励（来自C的订单），两种奖励在不同订单中叠加累计，互不排斥。


## 11. 技术实现要点

| 实现项 | 说明 |
|--------|------|
| 推荐关系存储 | 独立记录每位用户的推荐人，与挂靠关系分离 |
| 挂靠关系存储 | 独立记录层级结构，支持系统自动分配 |
| 推广奖励计算引擎 | 订单支付成功后触发，实时计算直推与间推奖励 |
| 直推计算 | 查找下单用户的推荐人，按对应位置比例计算整单金额 |
| 间推计算 | 逐层遍历挂靠层级，每件产品分配30积分，跳过推荐人层级 |
| 叠加逻辑 | 同一推广者可在不同订单中分别获得直推和间推奖励，分别入账 |
| 退款处理 | 原路扣减对应推广奖励，支持部分退款按比例扣减 |
| 负余额处理 | 允许负余额存在，后续奖励优先抵扣 |
| 数据审计 | 所有推广奖励记录可追溯，支持对账 |
